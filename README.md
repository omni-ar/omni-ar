The Greeks once asked a question about a ship repaired so many times that none of its original timber remained:

*Was it still the same ship?*

I think about that sometimes while building software.

A monolithic architecture starts simple. Then come the bottleneck failures, race conditions, async queues, and the silent rewrites needed to keep the system alive.

Somewhere in that cycle of tearing down and rebuilding, engineering stops being about syntax and starts being about state and survival.

**I'm Arjit.**  
Still replacing parts.  
Still building what survives.
